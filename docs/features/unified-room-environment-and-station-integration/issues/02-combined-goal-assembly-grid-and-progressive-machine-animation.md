# Combined Goal Assembly Site Task-Card Grid & Percentage-Driven Artificer Machine Animation

Type: `grilling`
Label: `wayfinder:grilling`
Status: resolved

## Question

How should the central `Goal Assembly Site` combine the dynamic grid of feature issue/task cards with the 1:1 `10 Artificer's Workshop` mechanical artifacts?

## Answer

Combine both on the central `10 Artificer's Workshop` riveted steel deck (over the crimson & gold fringed rug):

1. **Left Deck Zone — Feature Issue/Task Cards Grid (`#01..#0N`)**:
   - Renders the dynamic grid of feature issue/task socket cards (`unbuilt` tasks as chalk-cyan blueprint wireframes; `fitted` tasks as vibrant color-coded artifact cards).
2. **Right & Top Deck Zone — Percentage-Animated 1:1 `10 Artificer's Workshop` Machine**:
   - Renders the L-shaped copper steam pipeline, red valve wheel, brass pressure gauge, 3 interlocking trapezoid-tooth spur gears (`16-tooth` gold, `12-tooth` brass, `10-tooth` copper), digital green-screen control console, and concentric copper/steel Tesla coil.
   - Machine subsystems progressively animate based on the percentage of total tasks completed (`completionPct = fittedCount / totalCount`):
     - `0%`: Gauge needle at minimum (`-65°`), gears stationary, console screen dark, Tesla coil idle.
     - `1%–49%`: Steam puffs vent, pressure gauge needle climbs proportionally with `completionPct`, and the 3 interlocking spur gears rotate at speed proportional to `completionPct`.
     - `50%–79%`: Digital control console green screen powers on with live telemetry bars and red status indicator LED.
     - `80%–100%`: Yellow overdrive LED illuminates and the Tesla coil fires crackling cyan/white lightning arcs (`#d8f8ff`).
