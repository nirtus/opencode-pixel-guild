## Destination

Produce the authoritative specification (`spec.md`) and a playable 2D Canvas/PixiJS prototype for the **OpenCode Pixel Guild Visualizer**—a pure-spectator web companion (fed by a single telemetry ingress seam with three adapters: an OpenCode Host Plugin adapter using `@opencode/plugin` + `@opencode/plugin/tui`, a standalone `@opencode/client` bridge adapter connected to the shared local daemon via `Service.discover()`, and an in-process `Demo Guild Simulator` adapter) that represents all sessions across all projects and worktrees on the shared local OpenCode instance as `Workshop Room`s, root `Session`s and child `Subagent`s as autonomous `Guild Adventurer`s and `Squad Subagent`s (supporting both active choreography and persistent roster visibility), loaded skills as persistent `Skill Grimoire`s acquired at an `Arcane Lectern`, and built-in tools, plugin tools, MCP servers, and permission/question prompts as physical `Workstation`s, `Plugin Alcove`s, and `Quest Gate`s.

## Not yet specified

## Out of scope

- Interactive prompt-and-reply actions from the game UI (sending chat prompts, replying to permissions or forms)—kept in the OpenCode TUI (whereas session deletion `DELETE /api/session/{sessionID}` is in scope).
- 3D WebGL/Three.js voxel engines.
- Modifying OpenCode V2 core server internals.
