## Destination

Deliver a **100% project-agnostic**, self-contained, agent-executable setup runbook (`docs/agents/plugin-setup.md`), root `CLAUDE.md` pointer (`@AGENTS.md`), `AGENTS.md` context pointer, and universal `.gitignore` hygiene rules so any developer's coding agent (OpenCode, Claude Code, Cursor, Codex, Gemini CLI, GitHub Copilot, Antigravity, Pi, Devin, Droid, Kimi, Qwen, Hermes, Muse, Windsurf, Amp, etc.) can autonomously install, wire, and verify **`graphify`**, **`superpowers`**, and **`mattpocock/skills` (all 27 engineering & productivity skills + `/setup-matt-pocock-skills`)** in **any software repository**, backed by [Project-Agnostic Multi-Harness Agent Setup for `graphify`, `superpowers`, and `mattpocock/skills` Specification](./spec.md).

## Notes

- **Project-Agnostic Invariant (CRITICAL)**: The setup instructions in `docs/agents/plugin-setup.md` must contain **zero project-specific assumptions** (no hardcoded project names, no hardcoded `/home/ubuntu/...` paths, and no assumption that `docs/graphify-out/graph.json` or `docs/agents/` already exist). It must default `GRAPHIFY_OUT` to `docs/graphify-out` (syncing any CLI `graphify-out/` output into `docs/graphify-out/`), support both fresh and existing repositories, and include `/setup-matt-pocock-skills` per-repo scaffolding.
- **No-Duplication Rule for `mattpocock/skills`**: Pick **one** delivery mechanism per harness (native auto-updating plugin for Claude Code, Codex, and GitHub Copilot; dual-path `gemini skills install` for Gemini CLI; or deterministic sync of all 27 skills into `~/.agents/skills/` / `npx skills@latest` for OpenCode, Cursor, Devin, Windsurf, Amp, Pi, and other harnesses). Never install both a native plugin and editable skill files on the same harness.
- **Skills to Consult**: `writing-for-agents`, `graphify`, `opencode`, `find-skills`, `grilling`, and `domain-modeling`.
- **Single Source of Truth**: Keep `AGENTS.md` (and root `CLAUDE.md` containing `@AGENTS.md`) as the single source of truth for repository agent instructions, disclosing the full multi-harness setup runbook in `docs/agents/plugin-setup.md` via a concise context pointer.
- **Worktree Hygiene Invariant**: Machine-local `graphify` interpreter/root/lock/manifest/cache files (`**/.graphify_python`, `**/.graphify_root`, `**/.rebuild.lock`, `**/.graphify_detect.json`, `**/.graphify_transcripts.json`, `docs/graphify-out/cache/`, `docs/graphify-out/manifest.json`), untracked `/graphify-out/`, and harness-local hook/rule directories (`.opencode/`, `.superpowers/`, `.codex/`, `.cursor/`, `.claude/`, `.gemini/`, `.kiro/`, `.kilo/`, `.agents/`) must be gitignored and untracked so developer setups never leak machine-local paths or dirty `git status` in any repository.
- **Strict Git Commit Authority**: Never create git commits unless explicitly instructed by the human user.
